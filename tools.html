棚卸しシートから取り込む

棚卸しシート（.xlsx / .csv）をここにドロップ、またはクリックして選択
「棚卸しシート」タブを自動で読み取ります
スプレッドシートのURLをそのまま貼るだけで構いません（アドレスバーの https://docs.google.com/spreadsheets/d/… をコピー）。
その場合はスプレッドシート側で 共有 → リンクを知っている全員 → 閲覧者 にしてください。編集した内容がその場で棚に反映されます。
「ウェブに公開」で発行したCSVのURLも使えますが、Google側のキャッシュのため反映まで数分かかります。
GAS（script.google.com/macros/s/…/exec）のURLも貼れます。その場合、スプレッドシートの共有は制限付きのままで構いません。

設定

初回のみ：Supabase の SQL エディタで実行してください


    
スプレッドシート連動

    

    

    
連動中は、棚を開くたびにスプレッドシートの内容で上書きします。アプリ側での編集はスプレッドシート側の値に戻されるため、どちらか一方を正としてお使いください。

    スプレッドシートは「リンクを知っている全員が閲覧可」にする必要があります。URLを知る人は誰でも中身を見られるため、シートには社外秘の本文を書かず、リンクと説明だけに留めてください。
