棚卸しシートから取り込む

棚卸しシート（.xlsx / .csv）をここにドロップ、またはクリックして選択
「棚卸しシート」タブを自動で読み取ります
スプレッドシートのURLをそのまま貼るだけで構いません（アドレスバーの https://docs.google.com/spreadsheets/d/… をコピー）。
その場合はスプレッドシート側で 共有 → リンクを知っている全員 → 閲覧者 にしてください。編集した内容がその場で棚に反映されます。
「ウェブに公開」で発行したCSVのURLも使えますが、Google側のキャッシュのため反映まで数分かかります。
GAS（script.google.com/macros/s/…/exec）のURLも貼れます。その場合、スプレッドシートの共有は制限付きのままで構いません。

設定

初回のみ：Supabase の SQL エディタで実行してください


    
スプレッドシート連動

    
ここの設定は全社員で共通です。ひとりが設定すれば、全員の画面に反映されます。

    

    

    
連動中は、棚を開くたびにスプレッドシートの内容で上書きします。アプリ側での編集はスプレッドシート側の値に戻されるため、どちらか一方を正としてお使いください。

    スプレッドシートは「リンクを知っている全員が閲覧可」にする必要があります。URLを知る人は誰でも中身を見られるため、シートには社外秘の本文を書かず、リンクと説明だけに留めてください。

    

    

    

  

  

    
    
  







  
営業ツール棚 活用マニュアル

  

    
1. 探すとき

    
今いる営業プロセスの段を開いてください。段は上から、初回接触 → 現調 → 提案 → クロージング → 契約・引渡し → アフター → 社内勉強会 → バックオフィス → 業界・競合インプット、の順です。

    カードには必ず「誰が・いつ・何のために使うか」が書いてあります。開かなくても中身が分かるようにするためです。


    
1-2. 中身を確かめるとき

    
カードの名前か用途の文をクリックすると、右側に中身が開きます。スライドはその場でめくれ、動画は再生でき、PDFも読めます。別タブで開いて戻る手間が要りません。

    そのまま使うと決めたら、右下の「別タブで開く」を押してください。


    
2. お客様の前で開くとき

    
上の「お客様に出せるものだけ」を押してください。社内限定の資料が非表示になります。

    社外提示OK そのまま見せてよい　
    社内限定 見せてはいけない　
    顧客個別（要確認） 上長に確認してから


    
3. 足すとき

    
自分だけが持っている資料、個人PCにしかないExcelを優先して登録してください。

    1件だけなら「＋追加」、まとめてなら「元シート」から棚卸しシートに直接書いてください。

    用途の一行は必ず埋めてください。ここが空だと結局開いて確認することになり、棚の意味がなくなります。


    
4. 最新に保つ

    
資料を作り直したら、古い方を消さずに「状態」を「旧版（アーカイブ）」に変更してください。棚には最新版だけが並びます。消してしまうと、どれが最新か分からなくなった時に遡れません。

    版を上げたら「版・最終更新日」を書き換えてください。ここが1年以上前のままだと、カードに「要確認」が出ます。


    
5. 月に一度の棚卸し（管理担当者）

    
上の「要メンテナンス」を押すと、用途やURLが未記入のもの、1年以上更新されていないものだけが並びます。

    自分が管理担当になっているカードを確認し、直すか、旧版に落としてください。


    
6. タグ

    
タグはナレッジアプリと共通です。タグを押すとナレッジ側の該当項目に飛びます。

    開いて使うもの（ファイル・URL）はこの棚、読んで理解するもの（制度の解説・用語）はナレッジ、で使い分けてください。
