01このアプリで何が変わるか

名刺の枚数では評価しません。500人の課題を見つけ、100件の商談を生み、20件以上の受注につなげたかで評価します。

これまでのエキスポでは、名刺は集まっても、ヒアリングの中身が担当者の記憶にしか残らず、見込みの高いお客様が埋もれていました。誰がいつ何をするのかが決まらないまま日が過ぎ、気づいたときには温度が下がっています。

このアプリは、その場で聞いたことを点数に変えて、次にやることと期限まで自動で決めます。管理する対象が「会った人」から「いくらの粗利になる案件か」に変わります。

今回の目標 獲得リード500件／有効リード300件／優先リード150件／アポイント100件／現地調査・詳細提案50件／受注20件以上／紹介50件以上／60日以内の商談進行率90%以上

02使い始める前に

アクセス

スマホ、タブレット、パソコンのブラウザで下のURLを開きます。インストールは不要です。ホーム画面に追加しておくとアプリのように使えます。このマニュアルはアプリに内蔵されているので、いつでもマニュアルタブから読めます。

https://marubayashi-bot.github.io/refort-studio-new/expo-growth-360.html

ログイン

  1. 共有アカウントでログインするメールアドレスとパスワードは会社から配布されたものを使います。全端末で同じデータを見るために必要です。
  2. 端末名を入れる「受付1」「丸林スマホ」のように、誰のどの端末か分かる名前を入れてください。誰が入力したかを追えるようにするためです。一度入れれば次から聞かれません。
  3. ヘッダーのバッジを確認する画面上の丸いバッジが「同期済み」になっていれば、他の端末とデータがつながっています。
通信が切れたときは ログイン画面の「この端末だけで使う（オフライン）」から始められます。入力はこの端末に貯まり、回線が戻って同期すると全員に反映されます。会場で電波が悪くても入力を止めないでください。

同期バッジの見方

表示意味やること
同期済み全員と同じデータを見ていますそのまま使う
同期中送信しています数秒待つ
未送信 ◯件電波が届かず貯まっています電波の良い場所でバッジを押す
オフラインこの端末だけで動いていますあとでログインすれば送信されます
終了時の注意 バッジが「未送信」のままブラウザを閉じないでください。閉じる前に必ずバッジを押して「同期済み」にしてください。

03役割別クイックガイド

まずは自分の役割の欄だけ覚えてください。それ以外は必要になってから読めば十分です。

受付担当
  • 受付タブでカメラを起動しQRを読む
  • 読めなければ受付コード（EX-0001など）を手入力
  • 画面に出た招待者・紹介元・関心商品・過去商談を接客担当に口頭で伝える
  • 招待状がない方は「招待なしの来場者を登録」から名刺を撮影
  • 接客担当と商品を選んでヒアリング画面へ渡す
接客担当（営業）
  • 名刺交換から5分以内にヒアリングを入力
  • 共通8項目＋商品別の質問に答えるとランクが自動で出る
  • SAが出たらその場で次回の日程を確定
  • 「Googleカレンダーに登録」「お礼メールを作成」はボタンから
  • 最後に必ず紹介を依頼し「紹介を登録」に残す
マネージャー
  • 朝一番にダッシュボードの「本日対応すべき案件」を見る
  • 担当者が未割当のリードをその場で埋める
  • 商談・60日ルールの赤・オレンジを担当者に指示
  • 分析で次回設定率と平均停滞日数を見る
社長・幹部
  • 見るのは最上部の確度別の想定粗利パイプライン
  • 加重粗利（確率を掛けた数字）が実質の着地見込み
  • 失注理由と商品別の詰まりを分析で確認
  • 会期末に「全データをJSONで保存」を必ず実行

04当日の流れ

  1. お客様が受付に来る招待状またはスマホのQRコードを提示していただきます。
  2. QRを読み取る受付タブ →「カメラを起動」→ QRにかざす。読めないときは受付コードを手入力して「受付」を押します。
  3. お客様の情報が表示される来場予定時刻、招待した社員、紹介元、関心商品、区分、過去商談の有無が出ます。既存顧客や過去商談先の場合は「初対面ではありません」と警告が出るので、前回の話の続きから入ってください。
  4. 接客担当と商品を決める「担当を割り当ててヒアリングへ」を押すと、そのままヒアリング画面に進みます。
  5. ヒアリングを入力する共通の質問8項目と、選んだ商品の質問に答えます。入力するそばに判定パネルがあり、答えるたびにランクと点数が動きます。
  6. ランクを見て、その場で次を決めるSAなら次回商談日または現地調査日をその場で確定します。推奨アクションが日付つきで表示されるので、それに沿って動きます。
  7. 次回の予定を入れる「次回行動」「期限」「次回商談日時」を埋め、「Googleカレンダーに登録」を押すとカレンダーに入ります。
  8. 紹介を依頼する接客の最後に必ず聞きます。「紹介を登録」から紹介元・紹介先・商品を残します。
  9. 保存する「保存して判定」を押します。SAで次回予定が空だと警告が出ます。閉じずに日程を入れてください。
  10. 当日中にお礼メールを送るリード詳細の「お礼メールを作成」を押すと、聞いた課題が入った文面が自動で作られます。宛先と本文を確認して送信します。
接客の目安時間 ヒアリング入力は3〜5分です。お客様の前で入力して構いません。「後で入力する」は必ず抜けます。

05画面別の使い方

ダッシュボード

最上部の黒い帯が、このアプリでいちばん大事な数字です。

  • 想定粗利パイプライン：進行中の案件の粗利を、S・A・B・Cの色で積み上げています。帯の長さがそのまま金額の比率です。
  • 確度加重：各案件の受注確率を掛けて足した金額です。実質的な着地見込みとして見てください。
  • ファネル：獲得リードから受注・紹介まで8つの指標を、目標に対する達成率つきで表示します。
  • 本日対応すべき案件：Sランク未対応、次回予定なし、担当未割当、7日停滞、14日以上停滞、60日ルール残り7日、60日超過、本日期限。毎朝ここだけ見れば動けます。
  • 担当者ランキング：接客数だけでなく、有効ヒアリング数、S獲得数、次回確定数、紹介数、想定粗利で並びます。枚数では上位に行けません。

事前集客

エキスポの前に使う画面です。既存顧客、発電所オーナー、金融機関、税理士、不動産会社、土地所有者、経営者仲間、投資家などを登録し、担当者をつけて招待状況を管理します。

  • 7段階のステータス：未連絡 → 招待済み → 返信あり → 来場予定 → 来場確定 → 当日来場 → 商談化。当日来場と商談化は受付・ヒアリングで自動的に変わります。
  • QRボタン：その方専用の受付QRと受付コードが出ます。印刷して招待状に同封するか、メールにコードを記載します。
  • 案内メール：会場・来場予定・受付コード入りの文面が自動で作られます。
  • CSV取込：見出し行のあと、会社名／氏名／役職／区分／電話／メール／関心商品／紹介元／来場予定 の順に並べた表を貼り付けると一括登録できます。

受付

当日の入口です。カメラでQRを読むか、受付コードを手入力します。右側に本日の来場者が新しい順に並び、そのままヒアリングに入れます。

カメラが起動しないとき ブラウザにカメラの使用を許可してください。それでも駄目な場合は、受付コードの手入力だけで同じことができます。行列を止めないでください。

リード一覧

集まったお客様の一覧です。ランク、商品、担当、状態で絞り込め、加重粗利順・ランク順・次回期限順・停滞日数順に並べ替えられます。行を押すとヒアリング画面が開きます。

次回行動が空の案件は、赤い「未設定」が表示されます。この赤を消すのが、その日の仕事です。

商談・60日ルール

エキスポ後の主戦場です。PH01からPH08までのフェーズ別に件数と金額が並び、その下に要対応の案件が危険度順に出ます。いちばん下は進行中の全案件が、60日の残り日数が少ない順に並び、バーの伸び具合で経過が分かります。

紹介

紹介元、紹介先、関心商品、紹介予定日、お礼の有無、進捗を管理します。紹介依頼のトーク例も載せています。

そのまま使えるトーク 「本日のお話と同じように、発電所の発電量低下やPCS交換でお困りの方は、周囲にいらっしゃいますか？」
「投資や節税についてご相談を受けている経営者様がいらっしゃれば、一度情報提供の機会をいただけませんか？」

分析

転換率8種、失注理由のランキング、商品別の詰まり、担当者別の進捗（次回設定率・平均停滞日数・60日超過の件数）が出ます。失注理由を選ばずに失注登録することはできません。

設定

イベント名と会期、目標値、スタッフ、共有データの接続状態、CSV・JSONの出し入れ。デモデータを入れて練習し、消してから本番に入れます。

100点満点です。共通の質問で60点、選んだ商品の質問で40点。答えた内容から自動で計算されます。

判定理由と推奨アクション

判定パネルには、なぜそのランクになったかが札で表示されます。「決裁者本人」「FIT残7年以上」「発電量低下10%以上」のような加点要因と、「時期が未定」「次回面談が未確約」のような不足要因が並びます。不足要因が、その場で追加で聞くべきことです。

その下に、ランクに応じた推奨アクションが日付つきで出ます。Sランクなら、当日お礼メール、翌日電話、3日以内に商談または現地調査、7日以内に概算提案、14日以内に条件調整、60日以内に受注判断。この日付は商談開始日から自動計算されます。

0760日ルール

具体商談の開始から60日以内に、受注または明確な判断まで進めます。

期限の管理

状態色意味やること
残り7日以内赤期限が迫っている上司同席で打ち手を決める
60日超過赤（警告）ルール違反受注か見送りか、その日のうちに判断する

途中の停滞

期限内であっても、動いていなければ意味がありません。最終接触からの日数でも色がつきます。

状態色意味やること
3日間 行動なし黄止まりかけている今日中に一報を入れる
7日間 行動なしオレンジ温度が下がっている電話で状況確認。難しければ上司に相談
14日以上 行動なし赤失注リスクが高い上司同席で打ち手を決める

「行動」として記録されること

リード詳細で「保存して判定」を押した日、またはお礼メールを作成した日が、最後の行動日として記録されます。電話をしただけでは記録されません。お客様に接触したら、必ずアプリを開いてメモを残して保存してください。

60日を過ぎたら、決める 判断を先送りしたまま案件を残さないでください。追えないなら失注として理由を選び、次の案件に時間を使います。失注は悪いことではありません。放置が悪いことです。閉じることでパイプラインの数字が実態に合います。
起点は「商談開始日」 初期値は来場日です。実際に具体商談が始まった日が別にある場合は、リード詳細の「商談開始日」を書き換えてください。ここから60日を数えます。

08エキスポ後の動き方

  1. 毎朝、ダッシュボードを開く「本日対応すべき案件」に出ているものを、その日のうちに片づけます。件数がゼロになる日を目指します。
  2. 赤とオレンジから手をつける商談・60日ルールタブの上から順です。金額の大きさではなく、止まっている順に動かします。
  3. 接触したらその場で更新する次回行動と期限を必ず書き換えます。フェーズ（PH）も実態に合わせて進めます。
  4. 週に一度、失注を整理する追えない案件は失注理由を選んで閉じます。パイプラインの数字を実態に合わせるためです。
  5. 紹介の進捗を追う紹介予定日を過ぎているものは、紹介元へのお礼と状況報告を先に行います。

09守るルール7つ

アプリを作っただけでは成果は出ません。この7つとセットで初めて機能します。

  1. 名刺交換後、5分以内に最低限のヒアリングを入力する後回しにした分は必ず抜けます。お客様の前で入力して構いません。
  2. S・Aランクは、会場で次回予定を確定する「後日ご連絡します」で終わらせない。空のまま保存すると警告が出ます。
  3. 担当者が決まっていないリードを残さない誰の案件でもないものは、誰も動かしません。
  4. 次回行動と期限がない案件を登録完了にしない次に何をいつまでにやるかが書けないなら、それはまだ商談ではありません。
  5. 当日中にお礼連絡を完了する翌日では他社に先を越されます。
  6. 毎朝、未対応・停滞案件を確認するダッシュボードの上段だけで済みます。1分です。ここを毎日やるかどうかで、今回の成果が決まります。
  7. 商談開始から60日以内に、受注か見送りかを判断する判断を先送りしたまま案件を抱え続けないでください。

10困ったとき

カメラが起動しません

ブラウザからカメラの使用許可を求められたら「許可」を押してください。それでも駄目なら、受付コード（EX-0001など）を手入力すれば同じ処理ができます。行列を止めないでください。

QRを読んだのに「該当する受付コードがありません」と出ます

事前集客に登録されていない方です。「招待なしの来場者を登録」から名刺を撮影して新規登録してください。

電波が届かず、バッジが「未送信」のままです

入力は端末に残っているので、そのまま続けて構いません。電波の良い場所でバッジを押せば送信されます。送信が終わるまでブラウザを閉じないでください。

他の人が入力したはずのお客様が、自分の画面に出ません

バッジを押して同期してください。それでも出ない場合は、相手の端末が「未送信」のままの可能性があります。相手に同期を依頼してください。

同じお客様を2人が別々に登録してしまいました

片方のリードを開き、失注理由「その他」で閉じるか、管理者に統合を依頼してください。受付でQRを読んでいれば重複しません。飛び込み登録のときは、会社名で検索してから登録してください。

2人で同じ案件を同時に編集したらどうなりますか

後から保存した内容が残ります。接客担当を分けて入力してください。編集中に他の端末で更新があった場合は「他の端末で更新がありました」と表示されます。

商品を途中で変えたら、入力した内容は消えますか

消えません。共通の質問はそのまま引き継がれ、商品別の質問だけが入れ替わります。

停滞の日数はどこから数えていますか

最後に「保存して判定」を押した日、またはお礼メールを作成した日からです。まだ一度も保存していない場合は、商談開始日から数えます。電話や訪問をしたら、必ずアプリを開いて保存してください。

60日の起点はいつですか

リード詳細の「商談開始日」です。初期値は来場日ですが、実際に具体商談が始まった日が別にあれば書き換えてください。書き換えると残り日数も再計算されます。

ランクが思ったより低く出ます

判定パネルの札に不足要因が出ています。「時期が未定」「次回面談が未確約」などが表示されていれば、それを追加で聞けば上がります。点数を上げるために事実と違う入力をしないでください。読めない数字は意味がありません。

想定粗利の初期値は変えられますか

商品を選ぶと自動で入りますが、案件ごとに手で直せます。規模が分かった時点で実態に合わせてください。

お礼メールのボタンを押しても何も起きません

端末の標準メールアプリが設定されていない場合があります。設定するか、文面を手で作成してください。

間違えて失注にしてしまいました

リード一覧の絞り込みを「失注」に変え、該当案件を開いてフェーズと次回行動を入れ直し、保存してください。状態を戻す操作は管理者に依頼してください。

データは消えませんか

共有サーバー側に保存されているので、端末を変えても残ります。ただし会期の終わりには必ず「全データをJSONで保存」を実行し、共有フォルダに置いてください。

11管理者向け

初回セットアップ

  1. データベースを作るアプリの設定→「初回セットアップ用SQL」をコピーし、Supabase の SQL Editor で一度だけ実行します。2回目以降は不要です。
  2. スタッフを登録する設定→「＋ スタッフ追加」。氏名、チーム、役割を入れます。接客担当を割り当てるために、当日までに全員分を入れてください。
  3. 目標を設定する獲得リードから紹介獲得まで7つの目標値を入れます。ダッシュボードの達成率に反映されます。
  4. 招待者を取り込むCSV取込で一括登録し、担当者を割り当てます。QRコードは登録した時点で発行されます。
  5. 練習させる「デモデータを入れる」で6件のサンプルが入ります。全員に一度触らせ、終わったら「全データを消去」で戻します。本番前に必ず消してください。

会期中に見るもの

  • ダッシュボードの「本日対応すべき案件」。担当未割当と次回予定なしは、その日のうちに埋めさせます。
  • 分析タブの担当者別。次回設定率が低い担当者には、その場で指導します。
  • 各端末の同期バッジ。「未送信」が溜まっている端末がないか、休憩のたびに確認します。

会期後にやること

  • 「全データをJSONで保存」を実行し、共有フォルダへ。これがバックアップです。
  • リードCSV・紹介CSVを出力し、社内案件管理システムへ連携します。
  • 60日経過後、失注理由の集計を見て、次回のヒアリング項目と提案内容を見直します。
権限について 現在は全員が同じアカウントでログインするため、閲覧範囲の出し分けはできません。全員が全案件と金額を見られます。会期中の運用としては問題ありませんが、恒常運用に移す場合は社員ごとのアカウント発行が必要です。
